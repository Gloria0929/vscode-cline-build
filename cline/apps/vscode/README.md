# Coder

Autonomous coding agent right in your IDE. Coder can create and edit files,
run commands, use the browser, and more — with your permission every step of
the way.

## Features

- Plan & Act modes for complex, multi-step tasks
- Reads and edits files, runs terminal commands
- Browser automation for testing and scraping
- MCP (Model Context Protocol) server support
- Checkpoints: restore to any previous state
- Works with OpenRouter, Anthropic, OpenAI, and many more providers

## Getting Started

1. Open the Coder view in the Activity Bar
2. Open Settings and pick your API provider
3. Enter your API key and start coding

## Self-hosted Build

This is a self-hosted build: no account, no login, no telemetry.
Configure your own API key and everything runs locally.
